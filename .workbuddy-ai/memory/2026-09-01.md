## We withdrew a headline finding — this is now part of the pitch

The "risk-engine escalation" claim (0% → 23.1% → 14.3%) that research/10,
FINAL-SPRINT-PLAN and the README all quoted as Finding 2 **does not
survive testing**:

```
homogeneity chi-square 2.82 (denominator=all) / 3.04 (gate-reaching)
df=2, p ≈ 0.22–0.24        Cochran-Armitage trend z = 0.00, p = 1.00
```

5 challenges in 38–40 gate-reaching sessions. The 0/13 first segment has
a 95% upper bound of 23.1% — exactly the second segment's point estimate.
We had read noise as signal, and folded in a ~90% figure from a *different
run under different conditions*.

**Do not reintroduce this claim.** If a doc or the video script still
quotes "escalation over the run", it is stale.

## What replaced it — the venue study (stronger, and honest)

Recovered VM2's session evidence (it had never been in the repo; the A/B
had been citing n=94 from files nobody could see):

| Phase | Network | Challenge rate | 95% CI |
|---|---|---|---|
| P1 | Azure datacenter IP | 79.3% (23/29) | [61.6, 90.2] |
| P2 | residential IP | 12.7% (7/55) | [6.3, 24.0] |
| P3 | Azure datacenter IP, resumed | 100% (20/20) | [83.9, 100] |

datacenter (P1+P3) vs residential: z = 7.64, p = 2.1e-14.

It is an **A-B-A reversal**, which is the argument: a monotone confound
(key ageing, bot history) predicts P3 ≥ P2, and we see the opposite sign.
Confounds that remain (stated in the report docstring): venue ↔ clock
time, venue ↔ host, and key id not stored in session rows.

## Gotchas hit today

- Bash on Windows: `pkill` does not kill Windows chrome. Use
  `taskkill /F /IM chrome.exe`. 17 zombie chrome processes made
  Playwright fail with `ERR_INSUFFICIENT_RESOURCES` /
  `TargetClosedError`.
- `risk_venue_report.py --out ../artifacts/x.json` resolves relative to
  CWD, not to the script — it silently wrote to the repo-root
  `artifacts/` while `risk_curve.py` reads `app/artifacts/`. Watch the
  two `artifacts/` directories.
- Large Playwright smoke tests on this machine: kill chrome between runs.
